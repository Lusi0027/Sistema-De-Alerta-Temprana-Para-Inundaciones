# Sistema-De-Alerta-Temprana-Para-Inundaciones
Sistema de alerta temprana para inundaciones, proyecto final de Proyecto Integrador I en la Universidad Central del Este (UCE). Emplea un sensor ultrasónico y un ESP32 para medir el nivel del agua y alertar a los residentes antes de que llegue a sus viviendas, e integra una API meteorológica para obtener pronósticos.
